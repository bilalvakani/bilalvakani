## About me

I'm a full stack developer from Pakistan. I build web apps end to end: responsive interfaces with **React**, **Next.js** and **Tailwind CSS**, APIs with **Node.js**, **Express** and **NestJS**, data in **MongoDB**, **PostgreSQL** and **Redis**, and delivery on **AWS** with **Docker** and CI/CD.

I care about clean component design, small bundles, and interfaces that feel good on a phone.
